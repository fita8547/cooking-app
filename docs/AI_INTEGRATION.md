# AI 기능 통합 가이드

## 개요

애드쿠킹클래스는 OpenAI API를 활용하여 다음 AI 기능을 제공합니다:

1. **AI 레시피 생성**: 사용자의 재료와 건강 정보를 기반으로 맞춤형 레시피 생성
2. **재료 인식**: 냉장고 사진에서 AI가 자동으로 재료를 인식

## 설정 방법

### 1. OpenAI API 키 발급

1. [OpenAI Platform](https://platform.openai.com/api-keys)에 접속
2. 로그인 또는 회원가입
3. "Create new secret key" 버튼 클릭
4. 생성된 API 키를 안전한 곳에 복사

### 2. 환경 변수 설정

프로젝트 루트에 `.env` 파일을 생성하고 다음 내용을 추가:

```env
VITE_OPENAI_API_KEY=sk-your-actual-api-key-here
```

**중요:** 
- API 키는 `sk-`로 시작해야 합니다
- `.env` 파일은 절대 Git에 커밋하지 마세요 (이미 .gitignore에 포함됨)
- 프로덕션 환경에서는 환경 변수를 안전하게 관리하세요

### 3. 개발 서버 재시작

환경 변수를 변경한 후에는 개발 서버를 재시작해야 합니다:

```bash
# Ctrl+C로 서버 중지 후
npm run dev
```

## 사용 방법

### AI 레시피 생성

1. **재료 입력**
   - 레시피 추천 페이지로 이동
   - 보유한 재료를 수동으로 입력하거나 카메라로 촬영

2. **필터 선택**
   - "보유 재료만": 입력한 재료만으로 만들 수 있는 레시피
   - "일부 재료 추가 허용": 추가 재료가 필요한 레시피도 포함

3. **AI 레시피 생성 버튼 클릭**
   - 보라색 "AI 레시피 생성" 버튼 클릭
   - 5-10초 정도 대기
   - AI가 3개의 맞춤형 레시피를 생성

### 재료 인식 (Vision API)

1. **카메라 버튼 클릭**
   - 재료 입력 섹션에서 "촬영" 버튼 클릭

2. **사진 업로드**
   - 냉장고 또는 재료 사진 선택
   - AI가 자동으로 재료 인식 (약 3-5초)

3. **재료 확인**
   - 인식된 재료 목록 확인
   - ✓ 버튼: 재료 추가
   - ✕ 버튼: 재료 제외

## AI 기능 상세

### 레시피 생성 알고리즘

AI는 다음 정보를 고려하여 레시피를 생성합니다:

- **재료 목록**: 사용자가 입력한 재료
- **건강 프로필**: 나이, 성별, 목표 칼로리
- **알레르기**: 알레르기 재료는 자동으로 제외
- **식단 목표**: 체중 감량, 유지, 증가, 근육 증가
- **필터 모드**: 보유 재료만 또는 추가 재료 허용

생성되는 레시피 정보:
- 레시피 이름 및 설명
- 필요한 재료 (양, 단위 포함)
- 단계별 조리 방법
- 영양 정보 (칼로리, 단백질, 탄수화물, 지방)
- 난이도 및 조리 시간
- 적절한 이모지 아이콘

### 재료 인식 정확도

- **신뢰도 임계값**: 50% 이상인 재료만 표시
- **지원 재료**: 일반적인 식재료 (채소, 과일, 육류, 유제품 등)
- **최적 사진**: 밝은 조명, 명확한 초점, 재료가 잘 보이는 각도

## 비용 관리

### OpenAI API 요금

- **GPT-4o-mini**: 레시피 생성에 사용
  - 입력: $0.150 / 1M tokens
  - 출력: $0.600 / 1M tokens
  - 레시피 1회 생성: 약 $0.001-0.003

- **GPT-4o-mini Vision**: 재료 인식에 사용
  - 이미지 1장: 약 $0.002-0.005

### 비용 절감 팁

1. **캐싱 활용**: 동일한 재료로 여러 번 생성하지 않기
2. **배치 처리**: 여러 재료를 한 번에 입력
3. **사용량 모니터링**: [OpenAI Usage Dashboard](https://platform.openai.com/usage)에서 확인

## 문제 해결

### API 키 오류

**증상**: "OpenAI API 키가 설정되지 않았습니다" 메시지

**해결 방법**:
1. `.env` 파일이 프로젝트 루트에 있는지 확인
2. API 키가 `sk-`로 시작하는지 확인
3. 개발 서버를 재시작했는지 확인

### 레시피 생성 실패

**증상**: "레시피를 생성하는 중 오류가 발생했습니다" 메시지

**가능한 원인**:
1. **API 키 만료**: OpenAI 대시보드에서 키 상태 확인
2. **요금 한도 초과**: 결제 정보 및 사용량 확인
3. **네트워크 오류**: 인터넷 연결 확인
4. **API 서버 문제**: [OpenAI Status](https://status.openai.com/) 확인

### 재료 인식 실패

**증상**: 재료가 제대로 인식되지 않음

**해결 방법**:
1. **사진 품질 개선**: 밝은 조명, 명확한 초점
2. **재료 배치**: 재료가 겹치지 않도록 배치
3. **여러 번 시도**: 다른 각도에서 촬영

## 보안 고려사항

### 프로덕션 배포 시

현재 구현은 **개발 환경 전용**입니다. 프로덕션에서는:

1. **백엔드 API 구축**: OpenAI API 호출을 서버에서 처리
2. **API 키 보호**: 클라이언트에 노출되지 않도록 관리
3. **Rate Limiting**: 과도한 요청 방지
4. **사용자 인증**: 인증된 사용자만 AI 기능 사용

### 권장 아키텍처

```
[클라이언트] → [백엔드 API] → [OpenAI API]
                    ↓
              [데이터베이스]
              (캐싱, 로깅)
```
