# 데모 가이드

## 빠른 시작 (5분 데모)

### 1단계: 환경 설정 (1분)

```bash
# 프로젝트 클론 (이미 완료된 경우 생략)
cd cooking-app

# 의존성 설치
npm install

# .env 파일 생성 및 API 키 설정
cp .env.example .env
# .env 파일을 열어 VITE_OPENAI_API_KEY에 실제 키 입력

# 개발 서버 실행
npm run dev
```

### 2단계: 기본 기능 테스트 (2분)

#### 로그인
1. 브라우저에서 http://localhost:5173 접속
2. 아무 이메일/비밀번호 입력 (현재는 인증 없음)
3. "로그인" 버튼 클릭

#### 재료 입력
1. "레시피 추천" 메뉴 클릭
2. 재료 입력창에 다음 재료 입력:
   - 김치
   - 돼지고기
   - 두부
   - 양파
   - 계란

### 3단계: AI 기능 테스트 (2분)

#### AI 레시피 생성
1. "보유 재료만" 또는 "일부 재료 추가 허용" 선택
2. 보라색 "AI 레시피 생성" 버튼 클릭
3. 5-10초 대기
4. 생성된 3개의 맞춤형 레시피 확인

#### 요리 시작
1. 마음에 드는 레시피의 "요리 시작하기" 버튼 클릭
2. 단계별 가이드 확인
3. "다음 단계" 버튼으로 진행
4. 마지막 단계에서 평가 (맛있어요/보통이에요/별로에요)

## 전체 기능 데모 (15분)

### 1. 재료 인식 (Vision API)

#### 테스트 이미지 준비
- 냉장고 사진 또는 재료 사진 준비
- 권장: 밝은 조명, 명확한 재료 배치

#### 재료 인식 테스트
1. "레시피 추천" 페이지에서 "촬영" 버튼 클릭
2. 준비한 사진 업로드
3. AI가 재료 인식 (3-5초)
4. 인식된 재료 확인:
   - ✓ 버튼: 올바른 재료 추가
   - ✕ 버튼: 잘못 인식된 재료 제외

### 2. 건강 프로필 설정

1. "건강 식단" 메뉴 클릭
2. 다음 정보 입력:
   - 나이: 30
   - 성별: 남성/여성
   - 키: 170cm
   - 몸무게: 65kg
   - 목표: 체중 감량
   - 알레르기: 우유, 땅콩 (선택)

3. BMR 및 목표 칼로리 자동 계산 확인

### 3. 맞춤형 레시피 생성

1. "레시피 추천"으로 돌아가기
2. 재료 입력 (또는 이미 입력된 재료 사용)
3. "AI 레시피 생성" 클릭
4. 건강 프로필을 반영한 레시피 확인:
   - 목표 칼로리에 맞는 레시피
   - 알레르기 재료 제외
   - 영양 정보 표시

### 4. 요리 가이드

1. 레시피 선택 → "요리 시작하기"
2. 단계별 가이드 확인:
   - 진행 상황 바
   - 현재 단계 표시
   - 조리 방법 설명
3. "이전 단계" / "다음 단계" 네비게이션
4. 완료 후 평가

### 5. 식사 기록

1. "식사 기록" 메뉴 클릭
2. 통계 확인:
   - 총 기록 수
   - 총 섭취 칼로리
   - 좋아요 수
   - 평균 칼로리
3. 개인화 추천 확인 (좋아요 표시한 요리 기반)
4. 기록 관리:
   - 👍/👎 버튼으로 평가 변경
   - ✕ 버튼으로 기록 삭제

### 6. 재료 구매

1. "재료 구매" 메뉴 클릭 (홈 화면에서)
2. 부족한 재료 목록 확인
3. "보유 재료에 추가" 버튼으로 재료 추가
4. "구매하기" 링크로 쇼핑몰 이동 (시뮬레이션)

## 데모 시나리오

### 시나리오 1: 냉장고 파먹기

**목표**: 냉장고에 있는 재료로 저녁 식사 준비

1. 냉장고 사진 촬영 → AI 재료 인식
2. 인식된 재료 확인 및 수정
3. "보유 재료만" 필터 선택
4. AI 레시피 생성
5. 바로 조리 가능한 레시피 선택
6. 단계별 가이드 따라 요리
7. 완료 후 평가 및 기록

### 시나리오 2: 다이어트 식단 관리

**목표**: 체중 감량을 위한 건강한 식단 계획

1. 건강 프로필 설정 (목표: 체중 감량)
2. 목표 칼로리 확인 (예: 1800kcal)
3. 재료 입력 (건강한 재료 위주)
4. AI 레시피 생성
5. 칼로리가 낮은 레시피 선택
6. 요리 후 식사 기록
7. 일일 칼로리 섭취량 확인

### 시나리오 3: 알레르기 관리

**목표**: 알레르기가 있는 사용자를 위한 안전한 레시피

1. 건강 프로필에서 알레르기 설정 (예: 우유, 계란)
2. 재료 입력
3. AI 레시피 생성
4. 생성된 레시피에 알레르기 재료가 없는지 확인
5. 안전한 레시피로 요리

## 문제 해결

### 레시피가 생성되지 않음
1. 브라우저 콘솔 (F12) 확인
2. API 키 설정 확인
3. OpenAI 사용량 확인
4. 네트워크 연결 확인

### 재료 인식이 안됨
1. 사진 품질 확인 (밝기, 초점)
2. 재료가 명확하게 보이는지 확인
3. 다른 각도에서 재촬영

### 페이지가 느림
1. 개발 모드에서는 정상 (프로덕션 빌드 시 빠름)
2. 브라우저 캐시 삭제
3. 다른 브라우저에서 테스트
